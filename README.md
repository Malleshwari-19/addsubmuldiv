# Basic Arithmetic Operations in Java

##  About the Project

This repository contains four simple Java programs that demonstrate basic arithmetic operations: Addition, Subtraction, Multiplication, and Division.

Each operation is implemented in a separate Java class. The programs use predefined integer values and display the calculated result on the console.

This repository was created as part of my Java programming practice to understand basic arithmetic operations and Java program structure.

##  Programs Included

### 1. Addition (Add.java)
- Adds two integer numbers.
- Example: 10 + 20
- Output: 30

### 2. Division (Div.java)
- Divides one integer by another.
- Example: 40 / 4
- Output: 10

### 3. Multiplication (Mul.java)
- Multiplies two integer numbers.
- Example: 20 × 5
- Output: 100

### 4. Subtraction (Sub.java)
- Subtracts one integer from another.
- Example: 10 - 5
- Output: 5

##  How to Run

**Prerequisite:** Java Development Kit (JDK) installed.

Each program is stored in a separate Java file.

Compile and run the programs individually:

**Addition**
```bash
javac Add.java
java Add
```

**Division**
```bash
javac Div.java
java Div
```

**Multiplication**
```bash
javac Mul.java
java Mul
```

**Subtraction**
```bash
javac Sub.java
java Sub
```
